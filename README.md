# ⚡ MCQ AI Tutor — 2026 Edge Engine & MCP Server

Turso LibSQL (AWS Mumbai `ap-south-1`) এর ৫০,০০০+ বোর্ড প্রশ্নের ডাটাবেসকে কাজে লাগিয়ে তৈরি **আল্ট্রা-ফাস্ট এডুকেশনাল এআই মেন্টর ইঞ্জিন**।

---

## 🌟 মূল সুবিধাসমূহ (Key Features)

1. **In-Memory & Edge Caching:**
   - প্রথমবার কুয়েরি: Turso DB থেকে ডাটা আনে।
   - পরবর্তী রিকোয়েস্ট: **0ms থেকে 1ms** এ ক্যাশ থেকে রিটার্ন করে।
2. **AI Tutor Persona (বড় ভাইয়া):**
   - রোবটের মতো নয়, সহজ ভাষায় স্নেহশীল ও মোটিভেটিং ভঙ্গিতে স্টুডেন্টকে গাইড করে।
   - কুইজ নেওয়া, বোর্ড প্রশ্নের ট্রিকস বোঝানো এবং প্রশ্নের সমাধান দেওয়া।
3. **Model Context Protocol (MCP) Ready:**
   - Cursor, Claude Desktop বা যেকোনো LLM টুলে সরাসরি `/mcp` এন্ডপয়েন্ট কানেক্ট করা যাবে।
4. **Cloudflare Edge Deployment Ready:**
   - মাত্র ১টি কমান্ড দিয়ে ঢাকা/গ্লোবাল এজ নেটওয়ার্কে বিনামূল্যে হোস্ট করা সম্ভব।

---

## 🚀 লোকালি চালু করার নিয়ম (Run Locally)

```bash
# ১. ডিপেন্ডেন্সি ইনস্টল (অলরেডি ইনস্টল করা আছে)
npm install

# ২. সার্ভার রান করা
npm start
```

সার্ভার চালু হলে ব্রাউজারে যান:
👉 **`http://localhost:3000`**

সেখানে আপনি একটি ইন্টারেক্টিভ **ডার্ক-থিম ড্যাশবোর্ড** দেখতে পাবেন যেখানে লাইভ চ্যাট, র্যান্ডম কুইজ এবং ক্যাশ ল্যাটেন্সি দেখতে পারবেন।

## 🌐 ক্লাউডফেয়ারে ডিপ্লয় করার নিয়ম (Deploy to Cloudflare)

আপনার পিসির টার্মিনালে শুধু এই কমান্ডটি দিন:
```bash
npx wrangler deploy
```
এটি সাথে সাথে ক্লাউডফেয়ারের ফ্রি ঢাকা/মুম্বাই এজ নেটওয়ার্কে লাইভ হয়ে যাবে।

## 🔌 API Endpoints

| মেথড | এন্ডপয়েন্ট | বিবরণ |
|---|---|---|
| `GET` | `/` | স্টুডেন্ট ওয়েব ড্যাশবোর্ড ও চ্যাট UI |
| `GET` | `/api/stats` | ক্যাশ হিট-রেট ও সার্ভার হেলথ |
| `GET` | `/api/subjects` | ১৪টি বিষয়ের তালিকা (Cached) |
| `GET` | `/api/chapters?subject_id=ssc_physics` | অধ্যায়ের তালিকা (Cached) |
| `GET` | `/api/quiz?subject_id=ssc_physics&count=5` | ইনস্ট্যান্ট র্যান্ডম কুইজ |
| `GET` | `/api/search?q=অভিকর্ষজ` | ৫০,০০০ প্রশ্নে ফুল-টেক্সট সার্চ |
| `POST` | `/api/chat` | AI Tutor চ্যাট (`{ "message": "..." }`) |
| `POST` | `/mcp` | Model Context Protocol (JSON-RPC) |
