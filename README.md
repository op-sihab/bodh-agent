**"না বুঝে মুখস্থ নয়, পড়াশোনায় এবার গভীর বোধ।"**

**বোধ (BODH AI)** হলো বাংলাদেশের এসএসসি (SSC) শিক্ষার্থীদের জন্য তৈরি একটি তুখোড়, বাস্তববাদী এবং জিরো-হ্যালুসিনেশন (Zero-Hallucination) স্বায়ত্তশাসিত এআই একাডেমিক মেন্টর ইঞ্জিন। এটি সরাসরি **৫০,৮৫৫+ প্রামাণিক বোর্ড ও শীর্ষ ক্যাডেট কলেজের প্রশ্নব্যাংক**, রিয়েল-টাইম কগনিটিভ আরকিটাইপ অ্যানালাইসিস এবং স্বয়ংক্রিয় রিঅ্যাক্ট (ReAct) টুল অর্কেস্ট্রেশনের সমন্বয়ে পরিচালিত।

## 🌟 মূল বৈশিষ্ট্য ও আর্কিটেকচার (Key Capabilities)

### ১. 🛡️ জিরো-হ্যালুসিনেশন গ্রাউন্ডিং (Zero-Hallucination Architecture)
- **অফিশিয়াল এনসিটিবি (NCTB) সিলেবাস লক:**
  - **বাংলা ১ম পত্র:** ১৫টি গদ্য, ১৫টি কবিতা ও ২টি সহপাঠ (কাকতাড়ুয়া ও বহিপীর) সম্পূর্ণ ভেরিফায়েড। কোনো এইচএসসি পাঠ (যেমন: অপরিচিতা, বিলাসী) এর সাথে মিশবে না।
  - **তথ্য ও যোগাযোগ প্রযুক্তি (ICT):** ৬টি অফিশিয়াল অধ্যায় এবং ২,০২৬টি আসল বোর্ড প্রশ্ন সংযুক্ত।
  - **বিজ্ঞান ও গণিত:** পদার্থবিজ্ঞান (১৩টি অধ্যায়), রসায়ন (১২টি অধ্যায়), জীববিজ্ঞান (১৪টি অধ্যায়), সাধারণ গণিত (১৭টি অধ্যায়), উচ্চতর গণিত (১৪টি অধ্যায়), বিজিএস (১৫টি অধ্যায়)।
- **অক্ষত টপিক ফ্রেজ এক্সট্র্যাকশন (`KNOWN_TOPIC_PHRASES`):**
  - ‘সুভা ও বই পড়া’, ‘আম-আঁটির ভেঁপু’, ‘কপোতাক্ষ নদ’, ‘তোমাকে পাওয়ার জন্যে হে স্বাধীনতা’ ইত্যাদির মতো যৌগিক নাম অক্ষতভাবে চিনে নির্দিষ্ট প্রশ্ন তুলে আনে।
  - ‘গল্প’, ‘কবিতা’, ‘উপন্যাস’, ‘প্রবন্ধ’ ইত্যাদি সাধারণ শব্দগুলো আর সার্চে গিয়ে ভুল প্রশ্ন আনবে না।
- **অধ্যায় কলিশন গার্ড:**
  - আলোর প্রতিফলন (দর্পণ/Ch 8) বনাম আলোর প্রতিসরণ (লেন্স/Ch 9), পর্যায় সারণি (Ch 4) বনাম রাসায়নিক বন্ধন (Ch 5) সম্পূর্ণ আইসোলেটেড।

### ২. ⚡ রিয়েল-টাইম থট স্ট্রিমিং ও প্যাডাগোজিক্যাল রিঅ্যাক্ট লুপ
- **স্বচ্ছ চিন্তাভাবনা (`<thought>...</thought>`):** উত্তরের শুরুতে মেন্টর শিক্ষার্থীকে দেখায় সে কোন অধ্যায়ের কোন কনসেপ্ট এবং কোন বোর্ড প্রশ্ন নিয়ে কাজ করছে।
- **এসএসসি স্ট্রিমিং (`/api/chat/stream`):** লো-ল্যাটেন্সি Server-Sent Events (SSE) স্ট্রিমিং যাতে ব্রাউজারে টাইপরাইটার অ্যানিমেশনে উত্তর ভেসে ওঠে।
- **গাণিতিক সমীকরণ রেন্ডারিং:** KaTeX ইনলাইন (`$v = u + at$`) ও ব্লক সমীকরণ সমর্থন।

### ৩. 🎯 মাস্টার টাইপ ও কগনিটিভ আরকিটাইপ ব্লুপ্রিন্ট (Cognitive Archetypes)
- বাহ্যিক ফরম্যাটের বদলে প্রশ্নের পেছনের আসল গাণিতিক সূত্র ও কগনিটিভ ডেরিভেশন মিল রেখে একই টাইপের প্রশ্ন শনাক্ত করা।
- পরীক্ষকের প্রশ্ন ঘোরানোর কৌশল (Examiner Twist) ও ১০ সেকেন্ডের ট্রিকস বিশ্লেষণ।

### ৪. 📝 ইন্টারেক্টিভ কুইজ, এক্সাম মোড ও ফুল মার্কস সিক্রেট
- **এমসিকিউ (MCQ) মোড:** প্রশ্ন দেওয়ার সময় উত্তর গোপন রাখা এবং শিক্ষার্থী ক্লিক করার সাথে সাথে তাৎক্ষণিক মূল্যায়ন ও স্টেপ-বাই-স্টেপ সমাধান।
- **সৃজনশীল (CQ) মোড:** উদ্দীপক এবং ক, খ, গ, ঘ অংশের স্পষ্ট বিশ্লেষণসহ পরীক্ষকের মার্কিং গাইড (ক: ১ লাইন, খ: ২ প্যারা, গ: সূত্র-মান-একক, ঘ: সমাপনী বাক্য)।

## 🛠️ লোকাল সেটআপ ও রান করার নিয়ম (Quick Start)

### ১. ডিপেন্ডেন্সি ইনস্টলেশন:
```bash
# Bun দিয়ে (রেকমেন্ডেড ও দ্রুততম)
bun install

# অথবা npm দিয়ে
npm install
```

### ২. এনভায়রনমেন্ট কনফিগারেশন (`.env`):
```env
GEMINI_API_KEY=your_gemini_api_key_here
PORT=3000
NODE_ENV=development
```

### ৩. সার্ভার চালু করা:
```bash
# Bun দিয়ে চালু করুন:
bun server.js

# অথবা npm দিয়ে:
npm start
```
সার্ভার চালু হলে ব্রাউজারে প্রবেশ করুন: 👉 **`http://localhost:3000`**
